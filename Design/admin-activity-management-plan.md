# 관리자 활동·부원 출석 관리 구현 경계

[인테이크] 명확화 0건 · [부정검토] 이견 없음

## 승인 범위

- 부원 상세의 추가 선택기/출석 내역을 모든 연결 시트·탭·학기의 최신순 활동 목록+토글로 통합한다. 예정/없음은 표시하되 출석 수정 불가, 진행/완료만 편집한다. `/admin/attendance`의 화면은 유지한다.
- 관리자 활동 관리 내비·페이지: 대상 시트/탭 및 일정 선택, 예정/없음(선택 사유), 일정·상태·부원 출석 수정. 출석자가 있으면 없음 전환을 서버에서도 거부한다.
- 재확인 후 활동·출석·게스트·팀 및 정확한 시트 날짜 열을 삭제한다. 부원·학기·감사 로그·다른 활동은 보존한다.
- 새 편집 경로는 DB와 선택한 시트를 동기적으로 일치시킨다. 오류를 성공으로 삼키지 않으며 부분 변경을 복구하고 재시도 가능하게 한다. 조회/재동기화가 편집을 되돌려서는 안 된다.
- 예정 일정은 운영 중 Activity로 만들지 않아 대시보드 현재 활동을 가로채지 않게 한다. 기존 OTP·팀 상태머신은 유지한다.

## 서버 변경 경계

Application에 좁은 관리자 활동 관리 계약/DTO를 두고 Infrastructure 구현과 Web API/DI를 연결한다. 기존 ISheetClient/학기 서식 전략을 재사용하되 수정 시 선택 문서·탭·날짜 열의 식별과 원본 복구에 필요한 최소 계약만 확장한다. 시트 API는 서버에만 둔다.

같은 날짜가 다른 문서·탭에 있을 때 날짜만으로 다른 기록을 합치거나 지우지 않는다. DB 활동과 원천의 연결을 명시적으로 보존한다. 기존 데이터 연결 시 모호한 중복을 임의 추정하지 않고 명시적 충돌로 처리한다. 같은 날 여러 앱 세션은 그대로 보존한다. 복구 스냅샷에는 수식이 값으로 손실되지 않도록 원시 표현을 보존한다. 열 삽입 후 기록 실패, 쓰기 성공 후 응답 실패, DB 저장 실패 및 재시도를 테스트한다. 구조 변경으로 실패할 수 있는 위치를 가능한 원격 원자적 요청으로 묶고, 실패는 보상 후 전파한다. 원본 변경과 재동기화 사이 경쟁도 같은 조정 경계에서 다룬다.

부원 상세의 구형 per-activity API가 새 동기화 규칙을 우회하지 않도록 호출 경로를 확인한다. 다른 OTP/대시보드 흐름의 기존 동작은 불필요하게 변경하지 않는다.

## 화면 변경 경계

서버 계약 확정 후 Client의 HTTP facade, DI, MemberDetail 출석 영역, 신규 Activities 페이지, AdminNav만 변경한다. 기존 카드/폼/스위치/확인창/로딩·오류 패턴을 재사용하고 불필요한 의존성·새 모션은 추가하지 않는다. 실패 시 실제 상태를 다시 조회하고 성공 표시하지 않는다. 토글/저장 요청 중 중복 실행을 막으며 키보드·접근성 이름을 제공한다.

## 실행·검증 경계

기준 테스트: 202/202 통과 (`artifacts/admin-activity-management/baseline-test.log`). 5121 개발 프로세스 PID 57572의 Debug DLL 잠금은 사용자 승인 후 정확한 실행 경로를 재확인해 그 프로세스만 종료했다. 자동 재시작하지 않는다. 운영 Docker/원본 DB/원본 Sheets는 변경하지 않는다.

`dotnet build`, `dotnet test`, `node scripts/verify-admin-activity-management.cjs`로 검증한다. 브라우저는 독립 Verification 컨테이너의 tmpfs DB와 mutable 시트 대역을 사용한다. 기존 Verification no-op sync는 이 기능의 시트 증거로 인정하지 않는다. 새 대역은 실제 변경을 기억해야 하고 실제 SheetSyncService 경로를 검증해야 한다. 데스크톱/모바일 뷰포트에서 실제 DOM 측정과 합성 데이터 PNG를 수집한다. 이는 물리 iPhone/WebKit 검증이 아니다.

원시 로그/측정/PNG는 `artifacts/admin-activity-management/`, 최종 검증·독립 리뷰 문서는 `Design/admin-activity-management-{verification,review}.md`에 둔다. 모든 변경은 신선 컨텍스트 리뷰와 독립 계약 리허설 후 완료 감사에 제출한다.
