# 구글 시트 출석부 — 서식 명세 및 연동 설계

기준 스프레드시트: `11FS_2C1DLqW5-QTWXqpPtxd4jpeMz5rqxXr04T11zXU` (2026-10-12 실측, 서비스 계정 읽기 성공)

## 1. 시트(스프레드시트) 구성

- 관리자 설정에서 **종류별로 개별 등록**한다. 시작은 `출석부` 1종.
  엔티티 `SheetDefinition { Name, SpreadsheetId(또는 URL), Kind }`, `Kind=Attendance`만 출석 동기화 대상.
- 서비스 계정 키(JSON 본문)는 `Setting` 테이블(`Google:ServiceAccountJson`)에 저장하고
  관리자 설정 페이지에서 변경 가능. 첫 기동 시 user-secrets 값이 있으면 Setting으로 복사(시드).

### 공통 파싱 규칙 (전 출석 탭에 적용)

- **서식 자동 감지**: 1행에 활동 상태 Enum 값(`활동 예정`/`활동 완료`/`활동 없음`·`활동 상태`)이 있으면
  **신형(2026-2~)** — 1행 상태, 2행 날짜 헤더, 부원 3행~. 없으면 **구형(2023-2~2026-1)** — 1행 헤더, 부원 2행~.
- **날짜 열 판별**: 헤더 행이 정규식 `(\d{2})\.\s*(\d{1,2})\.\s*(\d{1,2})`에 매칭되면 활동 날짜(연도=20YY).
  끝 점은 요구하지 않는다 — 실측 2026-2의 12월 헤더는 `26. 12. 04 금`처럼 일 뒤 점이 없는 손입 서식.
  나머지(`OT 참여`, `N월 출석횟수`, `페널티(출석 -1)`)는 집계/기타 열 → 무시.
- **부원 구간**: '총 참여자 수' 또는 '탈퇴/퇴출자' 라벨 행부터는 집계·명단 구간 — 부원으로 읽지도 쓰지도 않는다.
- **셀 어휘(구형)**: `1` = 출석(지각 포함). `0`·빈칸·`우천 취소`·`- 추석 연휴 -`·`신입부원`·기타 문구 = 불참(기록 없음).
- **셀 어휘(신형)**: `출석` = 출석. `미출석`·`활동 불가`(부상 등)·빈칸 = 미출석로 흡수(앱 구분 없음).
- **상태행(신형)**: `활동 없음` 문구 포함 여부로 없음 판정(사유 괄호는 무시 — 예: `활동 없음(추석 연휴)`),
  `활동 예정` = 예정, 명시적 `활동 완료` = 완료(출석 0명이어도 활동으로 가져온다 — 상태행이 원천).
  상태가 **빈칸**인 날짜 열은 출석 마크가 있으면 완료로, 없으면 가져오지 않는다(미리 만들어진 빈 열 보호).
- **가져오기 대상**: 완료 열은 출석 1명 이상, 예정/없음 열은 항상 — 예정/없음은 `SheetDayMark`
  (날짜 PK + Scheduled/NoActivity)로 저장해 캘린더 표시에만 쓰고 Activity는 만들지 않는다.
  시트에서 완료로 바뀌면 동기화가 마크를 지운다(전체 상태 조정).

## 4. 부원 ↔ 시트 행 연결 (탭별 개별 매핑)

- 엔티티 `SheetMemberMapping { SheetDefinitionId, TabName, RowLabel, UserId }`.
  Unique: (Sheet, Tab, RowLabel) 및 (Sheet, Tab, UserId). 레코드 없음 = **미지정**.
- 관리자 > 부원 관리: 부원별로 탭(학기)마다 드롭다운으로 시트 행 라벨 선택.
  **추천**: 라벨에서 이름 추출(접미사 `24 만화` 제거)이 부원 이름과 일치하면 후보 최상단 배치+강조.
- 가져오기는 **명시적 매핑만** 사용한다(추천은 UI 편의). 미매칭 라벨은 경고로 집계.
- **비회원 학기 규칙**: 시트 가져오기 활동(CreatedByUserId=`sheet-import`)은 그 학기 탭에 매핑된 부원만
  미출석로 계산한다(기록·달력·학기 통계 분모 동일). 매핑 없는 학기 활동은 미출석으로 표시하지 않는다.
  앱에서 발생한 활동은 매핑과 무관하게 항상 미출석 계산에 포함된다.

## 5. 마감 내보내기

1. 활동 날짜와 **헤더 날짜가 일치하는 열**이 있으면 그 열에 기록(헤더는 건드리지 않음).
2. 없으면 **가장 가까운 이전/이후 날짜 열 사이에 열 삽입**(Sheets API `insertDimension`) 후 기록.
   이후 날짜 열이 없으면 마지막 날짜 열 바로 뒤(집계 열 앞)에 삽입.
3. 삽입한 헤더 텍스트는 그 탭 기존 서식을 따른다(예: `26. 10. 12. 월` — 0채움/요일은 기존 헤더에서 추정).
4. 셀(구형): 출석(매핑됨) = `1`, 그 외 = 빈칸.
   셀(신형): 출석 = `출석`, 그 외 = `미출석`(명시 기입). 기존 열 덮어쓰기 시 상태행(1행)은
   `활동 완료`로 갱신 — 2행 헤더를 건너뛰기 위해 분리된 열 쓰기(SheetWriteTarget.StatusColumn)로 보낸다.
   삽입 시에는 상태+헤더+부원이 연속이라 한 덩어리로 쓴다.
5. 진행 중 활동(BuildLiveColumn — 시작/시트 갱신): 신형 탭 상태행을 `활동 예정`으로 두고
   현재 출석자만 마크한다(미출석자는 공란 — 마감 전 출석 가능). 이미 `활동 완료`/`활동 없음`인 열은
   되돌리지 않고, 구형 탭은 진행 중 기록 자체를 하지 않는다(마감 때만 기록).
6. 열 삽입 시 총 참여자 수 행에 수식을 채운다(신형 `=COUNTIF(열3:열N,"출석")`, 구형 `=SUM(열2:열N)`) —
   삽입 본문과 별도 쓰기(SheetWriteTarget.StatusColumn)로 기록한다. '총 참여자 수' 행이 없는 탭은 생략.
7. 활동 취소: 그 날짜 **열을 통째로 삭제**한다(deleteDimension — 내용 지우기가 아니라 열 제거).
   열이 없으면 아무 것도 하지 않는다. best-effort — 실패해도 취소는 진행.
   수식 셀(총 참여자 수)은 USER_ENTERED로 기록해야 함수로 동작한다(RAW면 텍스트로 박힘) —
   WriteColumnAsync는 '='로 시작하는 셀이 있으면 USER_ENTERED, 아니면 RAW.
8. 마감 내보내기 성공 시 그 날짜의 SheetDayMark를 즉시 제거한다(완료 전환).

## 6. 동기화 흐름

- 시작 시 1회(SyncAsync): 시트 → DB 재반영 — 완료 열은 시트가 원천: 같은 날짜 활동이 있으면
  **출석 병합**(시트에 없는 출석 제거·추가, 유지 행은 시각·타입 보존 — 수기 수정이 반영됨),
  없으면 마감 활동으로 생성. 진행 중 활동 날짜가 완료로 표시됐으면 병합하지 않고 경고(활동 중 출석 보호).
  마크(예정/없음)는 탭 범위 전체 조정. 후 미내보낸 마감 활동 복구.
- 관리자 '시트 갱신'(ResyncAsync, 설정>구글 시트 연동): ①진행 중 활동 현재 출석 임시 기록
  (상태행 '활동 예정' 유지, 출석자만 마크·미출석자는 공란) → ②미내보낸 마감 내보내기 → ③전체 재반영(병합).
- 병합의 제거는 **그 탭에 매핑된 부원만** 대상 — 시트에 행이 없는 미매핑 부원의 출석은 시트가 표현할 수
  없으므로 지우지 않는다(왕복 보존). 완료 열을 없음/예정으로 되돌리면 그날의 **시트 유래 활동을 삭제**하고
  마크로 전환한다(앱 생성 활동은 OTP 실적 보존 — 경고만).
- 활동 시작 시: 상태행 '활동 예정' 기록(빈 출석, 실패 무시). 활동 마감 시: 즉시 완료+마크 내보내기,
  실패 시 마감 롤백 없이 다음 기동 복구.
