# 활동 기록 xlsx — 서식 명세 (가져오기·내보내기)

구글 시트 연동은 제거되었다(2026-11-02). 활동·출석 이력은 DB가 단일 원천이며,
관리자 설정 페이지에서 xlsx로 가져오기·내보내기한다. 이 문서는 그 파일 서식을 규정한다.

## 1. 파일 구성

- **가져오기**: 학기별 탭(예: `2023-1` ~ `2026-2`)이 담긴 xlsx(≤8MB). 탭 이름은 참고용이고
  파싱은 날짜 헤더 기준으로 동작한다. 회계 탭 등 활동·출석과 무관한 탭은 무시된다.
- **내보내기**: DB의 전체 학기(SemesterPeriod)를 탭 하나씩 담은 단일 파일. 어느 학기에도
  속하지 않은 기록은 `미분류` 탭에 담는다.
- 업로드 파일은 스트리밍 파싱 후 폐기된다 — 서버 디스크에 저장하지 않는다.

## 2. 탭 서식 (두 세대 자동 감지)

| 세대 | 1행 | 2행 | 부원 행 | 출석 마크 |
| --- | --- | --- | --- | --- |
| 신형(2026-2~) | 활동 상태 Enum | 날짜 헤더 | 3행~ | `출석` / 빈칸 |
| 구형(2023-2~2026-1) | 날짜 헤더 | — | 2행~ | `1`(또는 `1.0`) / `O`(2023-1) / 빈칸 |

- **서식 감지**: 1행에 `활동 예정`/`활동 완료`/`활동 없음`/`활동 상태` 값이 있으면 신형.
- **날짜 헤더**: `(\d{2})\.\s*(\d{1,2})\.\s*(\d{1,2})` 매칭(연도=20YY) 또는 엑셀 일련번호
  (40000~60000, 1900 날짜제 — 예: 46360 = 2026-12-04). 나머지 헤더(`OT 참여`, `세미나`,
  `회비 납부`, `N월 출석횟수`, `학기 총 출석` 등)는 특수·집계 열으로 건너뛴다.
- **라벨 활동 헤더**: 날짜 뒤에 텍스트가 더 있으면 라벨(예: `26. 09. 04. 금 OT` → 라벨 `OT`).
  가져오기는 (날짜, 라벨)로 기존 활동과 병합한다.
- **부원 라벨**: `이름 학번 학과`(2026) 또는 `이름`(구형). '총 참여자 수'/'탈퇴·퇴출자' 라벨 행
  부터는 집계·명단 구간이라 읽지 않는다.
- **상태행(신형)**: `활동 없음(사유)` → 없음 마크(사유 저장), `활동 예정` → 예정 마크,
  명시적 `활동 완료`(또는 빈칸+출석 마크 존재) → 완료 활동. 빈칸+출석 0은 가져오지 않는다.

## 3. 매핑·병합 규칙 (멱등)

- **완료 열**: 같은 (날짜, 라벨)의 종료 활동이 있으면 병합, 없으면 생성(`CreatedByUserId=xlsx-import`).
  출석은 (활동, 부원) 단위로 없는 것만 추가한다 — 같은 파일 재업로드 시 중복이 생기지 않는다.
- **부원 매칭**: 행 라벨의 `이름`+`학번`(숫자 토큰)으로 정확 매칭 → 이름 단독(유일할 때만).
  실패 행은 `UnmappedMember`(라벨 원문 보관)에 임시 저장하고, 관리자가 계정과 연동(Link)하면
  출석 기록이 해당 계정으로 이관된 뒤 임시 항목이 삭제된다.
- **예정/없음 열**: 그 날짜에 활동이 없을 때만 `DayMark`(Date PK + Kind + Note)로 저장한다.
  활동이 있는 날짜의 예정/없음 표시는 건너뛴다(왕복 내보내기 불변 유지).

## 4. 내보내기 그리드 (신형 통일)

- 1행 상태(`활동 완료`/`활동 예정`/`활동 없음(사유)`), 2행 날짜(`yy. MM. dd. 금` + 라벨 접미),
  3행~ 부원(`이름 학번 학과` 라벨, 미매핑 부원은 원본 라벨 그대로).
- 같은 날 여러 활동은 정기(라벨 없음) 먼저, 라벨 활동 뒤(칼럼 2개).
- 월이 바뀔 때마다 `N월 출석횟수` 칼럼, 마지막에 `학기 총 출석` 칼럼(계산값, 숫자 셀).
- 출석 셀은 `출석`, 미출석은 빈칸.
