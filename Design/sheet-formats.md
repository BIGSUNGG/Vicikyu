### 공통 파싱 규칙 (전 출석 탭에 적용)

- 1행 = 헤더. 0열 = `총 인원 :`. 부원 행은 1행부터, 0열이 라벨.
- **날짜 열 판별**: 헤더가 정규식 `(\d{2})\.\s*(\d{1,2})\.\s*(\d{1,2})\.`에 매칭되면 활동 날짜(연도=20YY).
  나머지(`OT 참여`, `N월 출석횟수`, `페널티(출석 -1)`)는 집계/기타 열 → 무시.
- **셀 어휘**: `1` = 출석(지각 포함). `0`·빈칸·`우천 취소`·`- 추석 연휴 -`·`신입부원`·기타 문구 = 불참(기록 없음).
- **가져오기 대상**: 출석(`1`)이 1개 이상인 날짜 열만. 전원 불참(우천취소 등) 열은 Activity를 만들지 않는다.
  (ponytail: 취소된 세션을 기록으로 남길 필요가 생기면 "빈 활동도 가져오기"로 전환)

## 4. 부원 ↔ 시트 행 연결 (탭별 개별 매핑)

- 엔티티 `SheetMemberMapping { SheetDefinitionId, TabName, RowLabel, UserId }`.
  Unique: (Sheet, Tab, RowLabel) 및 (Sheet, Tab, UserId). 레코드 없음 = **미지정**.
- 관리자 > 부원 관리: 부원별로 탭(학기)마다 드롭다운으로 시트 행 라벨 선택.
  **추천**: 라벨에서 이름 추출(접미사 `24 만화` 제거)이 부원 이름과 일치하면 후보 최상단 배치+강조.
- 가져오기는 **명시적 매핑만** 사용한다(추천은 UI 편의). 미매칭 라벨은 경고로 집계.
- **비회원 학기 규칙**: 시트 가져오기 활동(CreatedByUserId=`sheet-import`)은 그 학기 탭에 매핑된 부원만
  미출석로 계산한다(기록·달력·학기 통계 분모 동일). 매핑 없는 학기 활동은 미출석으로 표시하지 않는다.
  앱에서 발생한 활동은 매핑과 무관하게 항상 미출석 계산에 포함된다.

## 5. 마감 내보내기 (2026-2 탭)

1. 활동 날짜와 **헤더 날짜가 일치하는 열**이 있으면 그 열에 기록(헤더는 건드리지 않음).
2. 없으면 **가장 가까운 이전/이후 날짜 열 사이에 열 삽입**(Sheets API `insertDimension`) 후 기록.
   이후 날짜 열이 없으면 마지막 날짜 열 바로 뒤(집계 열 앞)에 삽입.
3. 삽입한 헤더 텍스트는 그 탭 기존 서식을 따른다(예: `26. 10. 12. 월` — 0채움/요일은 기존 헤더에서 추정).
4. 셀: 출석(매핑됨) = `1`, 그 외 = 빈칸.

## 6. 동기화 흐름 (변경 없음)

- 시작 시 1회: 등록된 출석 시트 → 탭별 파싱 → 매핑된 부원만 Attendance(Sheet 타입)로 캐싱,
  기존 날짜 스킵(멱등) → 미내보낸 마감 활동 복구.
- 활동 마감 시: 위 5번 절차로 즉시 내보내기, 실패 시 마감 롤백 없이 다음 기동 복구.
