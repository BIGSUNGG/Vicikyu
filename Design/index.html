🏐 배구부 앱 디자인 시안

스타일 시안(V1~V4)은 색감·무드 탐색, 레이아웃 시안(L1~L4)은 바운스 클럽(V4) 색감을 고정하고 화면 구조만 변형한 탐색입니다. 각 시안당 회원 핵심 화면 5장.

1
코트 오렌지
현재 MVP 오렌지 UI의 개선 진화판

지금 서비스의 오렌지 아이덴티티를 유지하면서 그라디언트 헤더, 큰 라운딩, 포인트 섀도우로 완성도를 높인 방향. 익숙함을 기준으로 개선을 검토할 때 기준점이 됩니다.

2
나이트 매치
다크 스포츠 · 네온 라임 액센트

경기장 야간 조명 컨셉. 어두운 배경에 라임/시안 네온으로 상태를 강조하고 대문자 레이블·모노숫자로 스포츠 통계 앱의 느낌을 살린 방향. 팀 히어로와 OTP가 가장 강하게 보입니다.

3
화이트 시트
클린 미니멀 · 여백 중심

색을 최소화하고 헤어라인과 여백으로 정보를 정리하는 방향. OTP는 언더라인 입력으로, 배지는 절제된 톤으로 바꿨습니다. 운영 도구로서의 담백함을 중시할 때 적합합니다.

동아리의 친근함을 최우선으로 한 방향. 굵은 라운딩과 파스텔 로테이션 칩, 눌리는 캔디 버튼, 도트 패턴 배경으로 장난기를 더했습니다. 부원 모집·홍보 인상에 유리합니다.

🎨 레이아웃 시안 — 바운스 클럽 색감 고정

L1
타일 보드
히어로 밴드 + 2칸 타일 그리드

홈은 물결 히어로 밴드 + 2×2 타일 대시보드 + 팀 요약 행, 팀 화면은 코트 라인 다이어그램에 팀을 배치, OTP는 2×2 원형 배치, 로그인은 상단 컬러 모자이크. 정보를 한눈에 스캔하는 보드형.

홈부터 보기 로그인 OTP 출석 팀 결과 MY
L2
헤로 스토리
풀블리드 헤로 + 타임라인 + 캐러셀

홈은 곡선 히어로에서 시작해 오늘의 흐름을 세로 타임라인으로 서사 전개, 팀은 가로 스와이프 캐러셀, 출석은 3단계 스탬프 진행 표시, MY는 출석률 도넛 링. 감성·스토리 중심 구성.

홈부터 보기 로그인 OTP 출석 팀 결과 MY
L3
컴팩트 리스트
행 기반 리스트 + 바텀시트 + 아코디언

홈은 섹션 헤더 + 정보 행 리스트로 밀도 높게, 출석은 화면 하단 고정 바텀시트에서 OTP 입력, 팀은 아코디언(나의 팀 펼침), MY는 주간 스트립 + 월간 캘린더. 한 화면에 많은 정보를 담는 운영 친화형.

홈부터 보기 로그인 OTP 출석 팀 결과 MY
L4
세그먼트 탭
탭 전환 + 커스텀 키패드 + 아바타 그리드

홈은 오늘/통계/회비 상단 세그먼트로 전환, 출석은 숫자 키패드로 직접 입력, 팀은 세그먼트로 팀을 골라 아바타 그리드로 확인, MY는 캘린더 헤드라인 + 기간 세그먼트. 앱스러운 인터랙션 강조형.

📚 기록 페이지 시안 — 하단 탭 확장(홈 · 기록 · MY · 관리자)

L1(바운스) 색감 + L2 홈 레이아웃(풀블리드 헤로 + 타임라인)을 고정하고, 기록 페이지의 콘텐츠 구성만 4가지로 탐색한 시안입니다.

R1
월간 타임라인
날짜별 활동 이력

히어로에 이번 달 요약(3월 8회 · 학기 12회 · 5위), 본문은 최근 순 세로 타임라인. 각 활동에 배정 팀을 팀색 점 + 배지로 표시하고 하단에 “이전 기록 더 보기”.

R2
팀 히스토리
팀별 배정 누적 + 최근 배정

“B팀과 가장 많이” 같은 히어로 카피 + 팀별 배정 횟수 바(A 4 · B 5 · C 3) + 최근 배정 타임라인. 랜덤 편성 결과를 재미 요소로 소비하는 구성.

연속 기록
스트릭 · 8연속 출석 중

“8연속 출석 중 · 개인 최고 9연속” 히어로 + 연속 도트 + 연속 횟수가 누적되는 타임라인. 게임적 동기부여 중심 구성(스트릭 산정 로직은 구현 시 확정 필요).

R4 보기

· 기록 시안(R1~R4)은 모두 MVP 보유 데이터(날짜·출석 시간·배정 팀·학기 통계·순위)만으로 구성했습니다. 단 R4의 연속 기록(스트릕) 집계는 현재 MVP에 없는 계산이라 구현 시 규칙 확정이 필요합니다.
· 최종 조합(F1~F4)은 레이아웃을 고정(홈·팀 L1 / 로그인 L3 / 출석 L4 / MY L2)하고 색감만 교체한 후보군입니다. 관리자 4장은 상태머신 제어(출석 시작→OTP→마감→팀 뽑기→확정)를 실제 흐름대로 표현했습니다.
· 레이아웃 시안(L1~L4)은 모두 바운스 클럽(V4) 색감을 공유합니다 — 색 토큰이 동일하므로 마음에 드는 레이아웃 언어를 고르면 그대로 조합할 수 있습니다.
· 모든 시안은 동일한 HTML 골격 + 시안별 CSS로 제작되어, 방향 확정 후 실제 Blazor(MudBlazor) 화면에 토큰(색·라운딩·타이포)만 이식하면 되는 구조입니다.
· 화면 속 데이터(팀 편성, 출석 기록 등)는 모두 가상 예시이며, 상태 흐름은 실제 서비스 상태머신 (출석 중 → 팀 확정 → 종료)를 따릅니다.
